# ICD Management System — Skeleton v0.2

Khung repository trước khi viết code.

## Stack đã chốt

- Backend: NestJS + TypeScript
- ORM: Prisma
- Database: MySQL 8.x / InnoDB
- Web: React + Vite
- Mobile: React Native + Expo
- ML: FastAPI
- Monorepo: pnpm workspace khi scaffold thật

## Quy tắc quan trọng

1. Đọc `RULES.md` ở root.
2. Đọc `RULES.md` gần module đang triển khai.
3. Các file code hiện chỉ là placeholder có comment tiếng Việt.
4. Chưa có logic chạy thật.
