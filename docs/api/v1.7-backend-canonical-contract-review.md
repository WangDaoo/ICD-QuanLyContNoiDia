## 1. Quy uoc chuan

Base URL: `/api`

Internal API auth:

```http
Authorization: Bearer <accessToken>
Content-Type: application/json
```

External Partner API auth:

```http
X-API-Key: <partner-secret-key>
Idempotency-Key: <uuid-or-business-key>   # bat buoc voi endpoint doi state
Content-Type: application/json
```

Response thanh cong dung envelope chung, tru endpoint file/export:

```json
{
  "data": {},
  "meta": {
    "requestId": "req_01HV...",
    "timestamp": "2026-09-21T10:00:00.000Z"
  }
}
```

Response loi:

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Du lieu khong hop le",
    "details": [
      {
        "field": "containerVisitId",
        "message": "containerVisitId must be UUID"
      }
    ]
  },
  "meta": {
    "requestId": "req_01HV...",
    "timestamp": "2026-09-21T10:00:00.000Z"
  }
}
```

Quy tac can sua backend:
- Route public phai quay ve route v1.7. Khong giu route drift vi khong can frontend hien tai.
- `container_visit.state` chi gom `PENDING`, `AUTHORIZED`, `IN_YARD`, `GATE_PASS_ISSUED`, `EXITED`, `CANCELLED`.
- Khong luu `current_location` va `hold_status` trong `container_visit`.
- Current location lay tu `container_location_log` co `ended_at IS NULL`.
- Hold lay tu `operational_hold` co `status = ACTIVE`.
- Khong dung generic `PATCH /api/containers/:visitId` de sua location/hold/state nghiep vu.
- Notification push la roadmap. Neu can de lai code, khong dua vao contract MVP v1.7.

## 3. Luong API nghiep vu

### 3.1 Manifest -> Container Visit

1. `POST /api/manifests` tao manifest `DRAFT`.
2. `POST /api/manifests/:id/master-bills` tao MBL.
3. `POST /api/master-bills/:id/house-bills` tao HBL.
4. `POST /api/manifests/:id/import-containers` tao `container` va `container_visit`.
5. Backend tao `container_visit.state = PENDING`.
6. Ghi `container_event` va `audit_log`.

### 3.2 Gate-in

1. `POST /api/gate/truck-visits` tao truck visit `SCHEDULED`.
2. `POST /api/containers/:visitId/movement-orders` tao movement order `DRAFT`.
3. `POST /api/movement-orders/:orderId/authorize`.
4. Backend lock `container_visit`.
5. Backend doi `container_visit.state: PENDING -> AUTHORIZED`.
6. `POST /api/gate/truck-visits/:id/arrive` doi truck visit sang `ARRIVED`.
7. `POST /api/containers/:visitId/gate-in`.
8. Backend tao `container_reception`.
9. Backend doi `container_visit.state: AUTHORIZED -> IN_YARD`.
10. Backend tao EDI CODECO gate-in neu co route EDI.

### 3.3 Yard assignment/current location

1. `GET /api/containers/:visitId/yard/recommendations` lay goi y.
2. `POST /api/containers/:visitId/yard/assign`.
3. Backend lock active location cu cua visit.
4. Backend dong `container_location_log.ended_at` neu co.
5. Backend tao `container_location_log` moi voi `ended_at = NULL`.
6. Current location luon doc tu log moi nay, khong doc tu `container_visit`.

### 3.4 Yard movement

1. `POST /api/containers/:visitId/yard/movements` tao `yard_movement.PENDING`.
2. `POST /api/yard/movements/:movementId/start` doi sang `IN_PROGRESS`.
3. `POST /api/yard/movements/:movementId/complete`.
4. Backend dong active `container_location_log`.
5. Backend tao `container_location_log` moi cho slot dich.
6. Backend doi `yard_movement.status = COMPLETED`.
7. Backend khong doi `container_visit.state`.

### 3.5 Inspection

1. `POST /api/containers/:visitId/inspections` tao `container_inspection.PENDING`.
2. `POST /api/inspections/:inspectionId/start` doi sang `IN_PROGRESS`.
3. `POST /api/inspections/:inspectionId/complete` doi sang `COMPLETED`.
4. Neu inspection fail va can block, tao `operational_hold.ACTIVE`.
5. Backend khong them state inspection vao `container_visit.state`.

### 3.6 Hold

1. `POST /api/containers/:id/holds` tao `operational_hold.ACTIVE`.
2. Readiness gate pass doc active hold bang `operational_hold.status = ACTIVE`.
3. `POST /api/containers/:id/holds/:holdId/release` doi hold sang `RELEASED`.
4. Backend khong ghi `container_visit.hold_status`.

### 3.7 Billing -> Payment

1. `GET /api/containers/:visitId/billing` lay tong quan.
2. `POST /api/containers/:visitId/service-orders` tao `service_order.DRAFT`.
3. `POST /api/service-orders/:orderId/confirm` doi `CONFIRMED`.
4. `POST /api/service-orders/:orderId/invoice` tao `invoice.ISSUED`.
5. `POST /api/invoices/:invoiceId/payments` tao `payment` va `payment_allocation`.
6. Backend cap nhat paid/outstanding qua allocation, khong tinh revenue truc tiep tu invoice total.

### 3.8 Gate Pass -> Gate-out

1. `GET /api/containers/:visitId/gate-pass` check readiness.
2. Dieu kien: `container_visit.state = IN_YARD`, khong active hold, billing paid/duoc mien theo policy.
3. `POST /api/containers/:visitId/gate-pass` tao `gate_pass.ACTIVE`.
4. Backend doi `container_visit.state: IN_YARD -> GATE_PASS_ISSUED`.
5. `POST /api/gate-pass/scan` validate token.
6. `POST /api/gate-out`.
7. Backend lock `container_visit` va `gate_pass`.
8. Backend doi `gate_pass.status = USED`.
9. Backend doi `container_visit.state: GATE_PASS_ISSUED -> EXITED`.
10. Backend dong active `container_location_log`.
11. Backend tao EDI CODECO gate-out.

### 3.9 Partner Handover

1. ICD core Gate-out da commit thanh cong va `container_visit.state = EXITED`.
2. `POST /api/handovers` tao `transport_handover.DRAFT`.
3. `POST /api/handovers/:id/publish` doi `READY_FOR_HANDOVER`.
4. Partner doc `GET /api/v1/external/handovers`.
5. Partner goi `accept`, backend doi `PARTNER_ACCEPTED`.
6. Partner goi `in-transit`, backend doi `IN_TRANSIT`.
7. Partner goi `warehouse-received`, backend doi `PARTNER_CONFIRMED`.
8. ICD goi `POST /api/handovers/:id/icd-confirm`, backend doi `COMPLETED`.
9. Partner API khong bao gio sua `container_visit`, Yard, Billing, Hold, Gate Pass.
