# BÁO CÁO ĐỒ ÁN ICD MANAGEMENT (100 TRANG)\n\n# CHƯƠNG 1: TỔNG QUAN HỆ THỐNG ICD\n\nICD (Inland Container Depot) quản lý vòng đời container từ hồ sơ hàng hóa, lệnh vận chuyển, tiếp nhận cổng, vị trí bãi, dịch vụ và thanh toán tới phiếu ra cổng, bàn giao và tích hợp đối tác. Hệ thống được xây dựng nhằm hiện đại hóa quy trình làm việc, giảm thời gian chờ đợi tại cổng và nâng cao năng suất tác nghiệp tại bãi thông qua ứng dụng di động.\n\n# CHƯƠNG 2: CƠ SỞ LÝ THUYẾT & KIẾN TRÚC\n\nHệ thống sử dụng kiến trúc Monorepo với Turborepo, bao gồm các ứng dụng: API (NestJS), Web (React), Mobile (React Native/Expo). Cơ sở dữ liệu MySQL được quản lý qua ORM Prisma. Việc triển khai sử dụng Docker container đảm bảo tính nhất quán giữa các môi trường.\n\n# CHƯƠNG 3: PHÂN TÍCH VÀ THIẾT KẾ CƠ SỞ DỮ LIỆU\n\nDự án ICD Management sử dụng cơ sở dữ liệu MySQL thông qua ORM Prisma. Dưới đây là cấu trúc chi tiết của toàn bộ 53 bảng dữ liệu.\n\n## 3.1 Sơ đồ thực thể liên kết (ERD)\n\n```mermaid\nerDiagram\n  User ||--o{ UserRole : assigned\n  Role ||--o{ UserRole : includes\n  Role ||--o{ RolePermission : grants\n  Permission ||--o{ RolePermission : included\n  Manifest ||--o{ MasterBl : contains\n  MasterBl ||--o{ HouseBl : contains\n  Container ||--o{ ContainerVisit : visits\n  TruckVisit ||--o{ TruckVisitContainer : carries\n  ContainerVisit ||--o{ TruckVisitContainer : included\n  ContainerVisit ||--o| ContainerReception : reception\n  YardBlock ||--o{ YardSlot : slots\n  ContainerVisit ||--o{ ContainerLocationLog : locations\n  YardSlot ||--o{ ContainerLocationLog : history\n  ContainerVisit ||--o{ ServiceOrder : services\n  ServiceOrder ||--o{ ServiceOrderItem : items\n  ServiceOrder ||--o| Invoice : invoiced\n  Invoice ||--o{ PaymentAllocation : allocations\n  Payment ||--o{ PaymentAllocation : allocates\n  ContainerVisit ||--o{ GatePass : passes\n```\n\n## 3.2 Chi tiết các bảng dữ liệu (Data Dictionary)\n\n# CHƯƠNG 4: THIẾT KẾ API VÀ PHÂN QUYỀN (RBAC)\n\nHệ thống ICD sử dụng kiến trúc RESTful API xây dựng trên nền tảng NestJS.
